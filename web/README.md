# web/ — PWA клиент (заглушка)

React + Vite + TypeScript PWA (SDD, раздел 4, Приложение A, разделы 4 и 10).

Здесь будет клиент: 8 экранов (Auth, Store Selector, Dashboard Home,
Product List, Product Detail, Inventory, Recommend, Analytics),
сканер штрихкодов html5-qrcode, графики Recharts.

Старт (когда будет инициализирован):

```bash
npm create vite@latest . -- --template react-ts
npm install
npm run dev
```

Backend API: `http://localhost:8000` (док — `/docs`).
